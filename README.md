## 🛠️ Stack & Ferramentas

As landing pages deste repositório utilizam tecnologias modernas focadas em performance, design responsivo e micro-interações:

* **Core:** React + TypeScript + Vite
* **Estilização:** Tailwind CSS (v4)
* **Componentes & Animações:** shadcn/ui, Spell UI, Lucide Icons
* **Design & Prototipação:** Figma
